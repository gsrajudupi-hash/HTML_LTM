Bullets and Numbering

Bulleted List: Unordered List

Use the <ul> tag when the order of the items does not matter.

  • Apples
  • Bananas
  • Oranges

Numbered List: Ordered List

Use the <ol> tag when items should appear in a particular order.

  1. Gather the ingredients
  2. Mix them together
  3. Bake until ready

Different Bullet Styles

Use the CSS list-style-type property to change unordered-list bullets.

Nested Lists

Put one list inside a list item to create a list within a list.

  • Fruit
    • Apples
    • Oranges
  • Vegetables
    • Carrots
    • Spinach

Definition List

Use <dl> for a list of terms, <dt> for each term, and <dd> for its description.
