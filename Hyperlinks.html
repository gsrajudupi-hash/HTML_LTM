Hyperlinks in HTML

Hyperlinks connect one page or resource to another. They are created with the anchor element, written as <a>.

Anchor Tag and Syntax

The href attribute tells the browser where the link goes. The text between the opening and closing tags is the clickable link text.

<a href="destination">Clickable link text</a>

For example: Visit Example.com

Important Parts

<a>
The anchor tag creates a hyperlink.
href
The destination URL, file path, or page location.
Link text
The readable content between <a> and </a>. Use text that makes the destination clear.
target="_blank"
Opens the destination in a new tab or window.
rel="noopener noreferrer"
Recommended with target="_blank" to prevent the new page from controlling the page that opened it and to avoid sending referrer information.
<a href="https://www.example.com" target="_blank" rel="noopener noreferrer">
    Open Example.com in a new tab
</a>

Open Example.com in a new tab

Common Types of Links

Link to another website

Use the complete URL, including https://.

<a href="https://www.example.com">Example website</a>

Go to Example.com

Link to another file in this folder

A relative path points to a file based on the current document's location.

<a href="Lists.html">Open the lists lesson</a>

Open the lists lesson

Link to a section on the same page

Give the destination element an id, then use that ID with # in the link.

<a href="#contact-info">Jump to contact information</a>
...
<h3 id="contact-info">Contact Information</h3>

Jump to contact information

Email and telephone links

Use mailto: for email and tel: for telephone links.

<a href="mailto:hello@example.com">Send an email</a>
<a href="tel:+15551234567">Call us</a>

Send an email | Call +1 555 123 4567

Contact Information

This is the section reached by the same-page link above. A fragment link uses the destination element's ID, such as #contact-info.
