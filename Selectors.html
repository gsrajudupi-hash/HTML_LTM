CSS Selectors

Selectors tell CSS which HTML elements to style.

1. Tag selector

The p selector styles every paragraph on this page.

Both of these paragraphs get the same basic style.

p { color: ...; }

2. Class selector

This paragraph has the highlight class.

Another element can reuse the same class.

.highlight { color: ...; }

3. ID selector

The page title has the unique ID main-title.

#main-title { color: ...; }
